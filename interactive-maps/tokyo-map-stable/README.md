## 為什麼保留這一版當交付版

`template/gen_map.py` 的自動排版（auto-layout）已經可以吃任意城市，但標籤位置是程式排的，
與這一版手排的結果**不一樣**——見 `../tokyo-autolayout-test/`。owner 2026-08-25 決定：
**發稿用這一版手調的**，自動排版那份標為測試、先不發稿。

手調版的代價是**無法重生**（標籤位置不在 `spots.py` 裡，是直接寫在產出的 HTML 上），
所以要改內容就得手改這個檔，或改用自動排版那條路。

## 動過的地方

- **2026-08-25**：把說明卡照片的 `loading="lazy"` 拿掉（只動這一個屬性）。
  說明卡是輪播的，每輪會插入一個新的 `<img>`，惰性載入的 intersection observer
  判不出它可見 → 照片會時有時無地閃掉、量到 `naturalWidth 0`。
  這個檔無法重生，所以是就地手改；`gen_map.py` 那邊也同步修好了。
